# NavSanrakshan Trust Website

Premium responsive NGO/Trust frontend built with React, Vite, Tailwind CSS, Framer Motion, React Router, Lucide icons, Swiper, and AOS.

## Run locally

```bash
npm install
npm run dev
```

## Build for Netlify

```bash
npm run build
```

Netlify settings:

- Build command: `npm run build`
- Publish directory: `dist`

The `netlify.toml` file is already included for single page app routing.
